# Задание по работе с базой данных "Библиотека"

## Часть 1: Создание структуры базы

Создать базу данных для библиотеки.

### Создать таблицы:

- **books** с полями:

  - `id` — первичный ключ с автоинкрементом
  - `название`
  - `год_издания`
  - `кол_страниц`
  - `id_автора` — внешний ключ, ссылающийся на таблицу `authors`

- **authors** с полями:
  - `id` — первичный ключ с автоинкрементом
  - `имя`
  - `фамилия`

---

## Часть 2: Наполнение данными

3. Заполнить таблицы данными: не менее **10 книг** и несколько авторов.

---

## Часть 3: Запросы на выборку данных

4. Вывести **название книги**, **год издания** и **ФИО автора** (имя и фамилию), отсортировав результат по году издания по убыванию.

5. Вывести все книги заданного автора по его имени и фамилии.

---

## Часть 4: Аналитические запросы

6. Вывести книги, у которых количество страниц **больше**, чем среднее количество страниц у всех книг в базе.

7. Вывести **3 самые старые книги** и посчитать суммарное количество страниц в них.

---

## Часть 5: Запросы на изменение и удаление

8. Написать запрос, который изменяет год издания на текущий год для одной **самой маленькой** (по количеству страниц) книги каждого автора.

9. Написать запрос, который удаляет автора, написавшего **самую большую** (по количеству страниц) книгу.
